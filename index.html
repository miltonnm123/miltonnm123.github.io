PROJECT_04

MilOS

MilOS is a C++ terminal application that simulates a small operating system with user accounts, password protected login, and a presistent virtual file system. Users can navigate folders, create and edit files, with their data saved between sessions. The system also includes a playable Snake game with custom level files and per-user high scored integrated directly into the virtual file system.

PROJECT_05

Dots Engine Optimization

Dots Engine Optimization was a school project focused on optimizing an existing C++/OpenGL simulation. My work focused on identifying and fixing performance bottlenecks through profiling, spatial partitioning, multithreading, GPU instancing, and improvements to collision detection. The goal was to increase the number of simulated entities while maintaining performance.
